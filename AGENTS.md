## Cursor Cloud specific instructions

- **What this is:** `CatFit / FitTrack`, a single Next.js 16 (App Router) + React 19 fitness PWA. There is no backend, database, or API — all user state lives in the browser (Zustand persisted to `localStorage`). Only one runtime service exists: the Next.js server.
- **Run/build/lint commands** are in `package.json` scripts (`dev`, `build`, `start`, `lint`). The dev server runs on `http://localhost:3000`.
- **No automated tests exist** (no test runner configured). Verify changes manually in the browser.
- **Lint is expected to fail** (`npm run lint` exits non-zero) due to pre-existing `react-hooks/set-state-in-effect` errors and many warnings — this is a code state, not an environment problem. Don't treat a non-zero lint exit as a setup failure.
- **PWA caveat:** the service worker (`@ducanh2912/next-pwa`) is disabled in `next dev` and only generated by `next build` (into `public/sw.js`, gitignored). The first user-facing screen redirects to `/onboarding`; after completing onboarding the app routes to the dashboard. To re-test the new-user flow, clear `localStorage`.
- **Internet note:** exercise images load from `cdn.jsdelivr.net`; the app otherwise works offline. The `import-exercises` / `generate-thai-steps` scripts need network but are build-time only — their output is already committed, so they are not needed to run or test the app.
